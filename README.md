# The Royal Design — Quotation Maker

Interior design quotation maker for **The Royal Design**, built with Next.js 15, React, TypeScript, Tailwind CSS, and shadcn/ui.

Same product as Build 4 Atelier, rebranded for The Royal Design (separate GitHub repo, Vercel project, and Neon database).

## Local setup

```bash
npm install
cp .env.example .env.local
# add Neon DATABASE_URL
npm run db:push
npm run dev
```

See `DEPLOY.md` and `.cursor/project.json` for deploy details.
